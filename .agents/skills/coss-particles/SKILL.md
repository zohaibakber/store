# COSS particles

Search [the catalog](references/catalog.md) for the relevant component or interaction; read only matching sections. It preserves the bundled particle names and JSON links.

Fetch the selected manifest at `https://coss.com/ui/r/<particle-name>.json` and adapt its source to the installed components, imports, and project styling. A manifest is source material; inspect its changes before installing it over local files.

Browse visual examples at <https://coss.com/ui/particles>. Paths such as `apps/ui/registry/default/particles/` belong to the upstream COSS repository, not this project.
