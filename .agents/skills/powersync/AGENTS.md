# PowerSync skill maintenance

Keep `SKILL.md` as the task router and put backend or SDK details in the relevant references. The word "operator" in references means the person requesting the work; "user" may mean an application end-user.

Reference workflows describe their respective setup paths. Apply only the steps needed for the requested task and installed versions. Preserve existing infrastructure ownership, deployment authorization, upload durability, and tenant isolation. Local implementation and read-only diagnosis do not require deployment or repeated onboarding questions.

When changing this skill, check that routing reaches the relevant references and that examples do not override project tooling or scope. Do not run live deployment commands merely to validate documentation.
